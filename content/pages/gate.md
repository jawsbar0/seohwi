## 개요
공간이 찢어져 다른 장소와 연결되는 균열.

- 발생 원인 불명. 예고 없이 출현.
- 방치 시 확장됨.
- 내부 가장 깊은 곳의 **핵**을 파괴해야 폐쇄됨.

## 등급
수호형 이형의 위협도와 균열 규모를 기준으로 E~S급 6단계로 분류.

| 등급 | 규모 | 대응 |
|---|---|---|
| E | 출입문 크기의 균열 | 길드 소규모 팀, 3학년 실습 동행 수준. 반나절 내 처리 |
| D | 건물 한 층 규모 | 길드 주력 의뢰. 4학년 파견실습 상한 |
| C | 센터 배정 기준선 | 주로 센터 C·D계열. 수호형부터 위험 |
| B | 내부가 마을 규모로 왜곡 | B계열 이상 투입. 주변 민간인 대피 |
| A | 사망자 발생 등급 | A계열 투입. 위험수당 최고 |
| S | 재해급 | 다수 팀 합동, 본부 지휘관 출동. 도시 단위 대피. 수년에 1회 |

## 대응 절차
출현 감지(인식기 알림·재난문자) → 봉쇄선 설치 → 측정반 등급 판정 → 팀 편성(센티넬·가이드·탐색인원 필수) → 진입 → 핵 파괴 → 붕괴 전 탈출 → 약 1시간 후 잔류오염 정화.

| 용어 | 설명 |
|---|---|
| 붕괴 | 핵 파괴 후 10분 안팎에 폐쇄. 내부 잔류 시 행방불명 처리 |
| 범람 | 처리 지연 시 이형이 외부로 유출. 등급이 높을수록 빠름 |
| 핵석 | 파괴된 핵의 파편. 에너지·장비 소재로 고가 거래되며 길드의 주 수입원 |

## 내부 법칙
- 진입할 때마다 내부 형태가 달라짐.
- 시간 흐름이 외부와 다름. 내부 1시간이 외부 수 분~반나절.
- 방향감각과 통신이 차단되어 탐색인원이 길잡이 역할을 함.
- 센티넬의 수치가 외부보다 빠르게 감소하여 **가이드 동행이 원칙**.
- 하늘색이 어긋나 보이고, 소리가 한 박자 늦게 들림.
- 핵은 최심부에서 맥박처럼 빛나는 결정이며, 수호형이 지킴.

### 지형
| 지형 | 특징 |
|---|---|
| 폐허형 | 무너진 도시 잔해. 가장 흔함. 엄폐물 많음 |
| 숲·늪형 | 빛이 거의 없음. 오염형 이형 다수 |
| 동굴형 | 좁은 통로가 얽힘. 탐색인원 없이 진입 불가 |
| 회랑형 | 동일한 복도가 반복되는 공간 왜곡. 길을 잃으면 탈출 불가 |
| 수몰형 | 물에 잠긴 구역. 물·바람 계열에 유리 |

## 이형
게이트에서 출현하는 괴생명체. 지구 생물을 변형한 형태가 많으며, 사망 시 검은 잔해로 흩어짐.

| 분류 | 특징 |
|---|---|
| 수호형 | 핵을 지키는 대형 개체. 게이트 등급의 기준 |
| 군체형 | 소형이나 무리 지어 이동. 일반인 피해 대부분을 차지 |
| 포식형 | 단독 사냥. 능력 파동에 이끌림 |
| 오염형 | 감각 교란으로 센티넬에게 부하를 줌 |
| 변이체 | 분류 외 개체. 드묾 |
